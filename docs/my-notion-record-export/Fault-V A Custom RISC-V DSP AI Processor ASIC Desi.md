## cpu版本與架構

| **V1：基礎 RISC-V CPU｜W1～W15** | **架構與規格** | **驗收標準** |
| --- | --- | --- |
| CPU 核心 | 32-bit、多周期、單指令依序執行、FSM 控制 | 各類指令能依正確流程完成，不發生錯誤寫回或 PC 更新 |
| 指令集 | RV32I 基礎整數指令：算術、邏輯、移位、比較、LUI／AUIPC、分支、跳躍、Load／Store、FENCE、ECALL／EBREAK | 每條支援指令都有測試，包含適用的邊界值；不只驗證範例程式 |
| Register File／ALU | 32×32-bit、兩讀一寫、x0 固定為零；32-bit 整數 ALU | x0、signed／unsigned 比較、移位、加減截斷等行為正確 |
| PC／Reset | 32-bit PC；從 `0x00000000` 啟動；高有效同步 reset | 啟動、順序執行、分支、跳躍與重置結果正確 |
| 記憶體 | FPGA 基準：16 KiB 指令＋16 KiB 資料；Little-endian；指令／資料分離介面 | 各寬度讀寫、符號擴展、byte enable 與對齊檢查正確 |
| 記憶體控制 | 請求／完成握手，全核心最多一筆未完成交易 | 不同回應延遲下仍正確，不重複讀寫、不漏交易 |
| 錯誤處理 | 非法指令、未對齊、存取失敗、ECALL／EBREAK：停止並記錄原因與位址 | 錯誤資訊正確，停止後不再啟動新指令或交易 |
| 執行環境 | 裸機；狀態暫存器回報結果；不含 Pipeline、Cache、MMU、外部中斷及標準 machine-mode trap／CSR | Fibonacci、迴圈、函式呼叫／返回、記憶體程式結果正確 |
| FPGA 周邊 | PYNQ-Z2、UART 傳送、GPIO、預先載入程式 | 指定 clock 約束下時序通過；實板程式與周邊可重複正常運作 |
| 交付成果 | RTL、testbench、測試程式、規格、FPGA 專案與結果紀錄 | 能依文件重現測試與板上展示；相容性聲明不超過已驗證範圍 |

| **V2：DSP／AI 擴充 CPU｜W16～W19** | **架構與規格** | **驗收標準** |
| --- | --- | --- |
| 基礎核心 | 保留 V1 多周期 RV32I 核心 | V1 全部回歸測試持續通過 |
| 自訂指令集 | 3～5 條 DSP／AI 指令；MAC、DOT4 為候選，依 benchmark 定案 | 每條指令的編碼、輸入、輸出、signed、位寬與溢位行為都有明確定義 |
| 自訂執行單元 | 接入 CPU Datapath；可共用或並行配置乘法／加法硬體 | 結果與獨立參考模型一致，包含負數、極值與其他邊界情況 |
| 多周期控制 | 執行單元採請求／完成控制，CPU 等待後寫回 | 不提前寫回、不重複啟動；reset 與連續執行行為正確 |
| 指令解碼與寫回 | 使用適當 custom 編碼空間，接回 Register File | 不誤判基本指令，目的暫存器及 x0 行為正確 |
| FPGA 整合 | 在 Z2 驗證；資源不足時再評估 ZU | 擴充後功能與時序通過，能實際執行自訂指令程式 |
| Benchmark | 基本 RV32I 軟體版本與自訂指令版本執行相同工作 | 輸出一致；保留 cycle、頻率、執行時間及 FPGA 資源比較，不預設加速倍數 |
| 交付成果 | 擴充 RTL、自訂 ISA 文件、參考模型、測試及 benchmark 報告 | 結果可重現，能解釋效能收益與硬體成本 |
